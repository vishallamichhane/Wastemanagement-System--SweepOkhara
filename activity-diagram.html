SweepPokhara — Waste Management System

Activity Diagram • System Workflow Activities

flowchart TD
    START(((Start))) --> VISIT[Visit SweepPokhara Website]
    VISIT --> IS_REG{Registered?}
    
    IS_REG -->|No| REGISTER[Register with Email/Google]
    REGISTER --> VERIFY[Verify Email]
    VERIFY --> SAVE_USER[Save User to Database]
    SAVE_USER --> LOGIN
    
    IS_REG -->|Yes| LOGIN[Login to System]
    LOGIN --> AUTH{Authenticate}
    AUTH -->|Failed| LOGIN
    AUTH -->|Success| ROLE{User Role?}
    
    ROLE -->|User| U_DASH[Open User Dashboard]
    ROLE -->|Collector| C_DASH[Open Collector Dashboard]
    ROLE -->|Admin| A_DASH[Open Admin Dashboard]
    
    %% ---- USER ACTIVITIES ----
    U_DASH --> U_ACT{Select Activity}
    U_ACT --> SCHED[View Pickup Schedule]
    U_ACT --> SUBMIT[Submit Waste Report]
    U_ACT --> TRACK[Track My Reports]
    U_ACT --> PROFILE[Update Profile]
    
    SUBMIT --> FILL[Fill Report Form]
    FILL --> ADD_IMG[Upload Images]
    ADD_IMG --> ADD_LOC[Add GPS Location]
    ADD_LOC --> SELECT_TYPE[Select Report Type]
    SELECT_TYPE --> SEND_REPORT[Submit Report]
    SEND_REPORT --> AUTO_ASSIGN[System Auto-Assigns Collector]
    AUTO_ASSIGN --> REPORT_SAVED[Report Saved: Status in-progress]
    REPORT_SAVED --> U_ACT
    
    SCHED --> U_ACT
    TRACK --> U_ACT
    PROFILE --> U_ACT
    
    %% ---- COLLECTOR ACTIVITIES ----
    C_DASH --> C_ACT{Select Activity}
    C_ACT --> VIEW_TASK[View Today Tasks]
    C_ACT --> VIEW_REP[View Assigned Reports]
    
    VIEW_TASK --> HAS_TASK{Tasks Available?}
    HAS_TASK -->|No| C_ACT
    HAS_TASK -->|Yes| START_TASK[Start Task]
    START_TASK --> DO_PICKUP[Perform Waste Pickup]
    DO_PICKUP --> DONE_TASK[Mark Task Completed]
    DONE_TASK --> NOTIFY_USER[System Notifies Ward Users]
    NOTIFY_USER --> C_ACT
    
    VIEW_REP --> UPD_REP[Update Report Status]
    UPD_REP --> MARK_DONE[Mark Report Resolved]
    MARK_DONE --> PENDING_VER[Status: Pending Verification]
    PENDING_VER --> C_ACT
    
    %% ---- ADMIN ACTIVITIES ----
    A_DASH --> A_ACT{Select Activity}
    A_ACT --> MGR_USERS[View All Users]
    A_ACT --> MGR_COLL[Manage Collectors]
    A_ACT --> REV_REP[Review Reports]
    A_ACT --> ANALYTICS[View Analytics]
    
    MGR_COLL --> COLL_ACT{Action?}
    COLL_ACT --> CREATE_C[Create Collector]
    COLL_ACT --> EDIT_C[Edit Collector]
    COLL_ACT --> DEL_C[Delete Collector]
    CREATE_C --> A_ACT
    EDIT_C --> A_ACT
    DEL_C --> A_ACT
    
    REV_REP --> PICK_REP[Select Pending Report]
    PICK_REP --> DECISION{Approve or Reject?}
    DECISION -->|Approve| APPROVE[Mark Report Resolved]
    DECISION -->|Reject| REJECT[Send Back to Collector]
    APPROVE --> SEND_EMAIL[Send Resolution Email to User]
    SEND_EMAIL --> A_ACT
    REJECT --> A_ACT
    
    MGR_USERS --> A_ACT
    ANALYTICS --> A_ACT
    
    U_ACT --> LOGOUT[Logout]
    C_ACT --> LOGOUT
    A_ACT --> LOGOUT
    LOGOUT --> ENDED(((End)))
