About Sequence Diagram

This simplified diagram shows the three main workflows in SweepPokhara: (1) User submits waste reports, (2) Collector manages and completes tasks, (3) Admin verifies and approves reports. All interactions flow through the central system and database.

    Note over U,A: 1. User Report Submission
    U->>S: Login
    S-->>U: Auth Token
    U->>S: Submit Report (GPS, Images, Description)
    S->>DB: Save Report & Auto-Assign Collector
    DB-->>S: Report Saved (Status: in-progress)
    S-->>U: Report ID & Confirmation Email

    Note over C,A: 2. Collector Task Management
    C->>S: Login
    S-->>C: JWT Token
    C->>S: View Today's Tasks
    S->>DB: Get Tasks
    DB-->>S: Task List
    S-->>C: Display Tasks
    C->>S: Complete Task
    S->>DB: Update Task Status
    S-->>C: Task Completed
    S-->>U: Pickup Completion Email

    Note over C,A: 3. Report Update & Verification
    C->>S: Mark Report as Resolved
    S->>DB: Update (Status: pending-verification)
    S-->>C: Awaiting Admin Approval
    
    A->>S: Login & View Reports
    S->>DB: Get Pending Reports
    DB-->>S: Reports List
    S-->>A: Display Reports
    A->>S: Approve Report
    S->>DB: Update (Status: resolved)
    S-->>A: Report Approved
    S-->>U: Resolution Email
